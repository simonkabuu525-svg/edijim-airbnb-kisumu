# Edijim AirBnB Kisumu

Modern, high-performance website for **Edijim AirBnB Kisumu** (Cassabela Apartments, opposite Metropark Hotel, Tom Mboya Estate, Kisumu, Kenya).

## Features
- **Cinematic Experience**: Luxury architectural showcases with sound effects (Web Audio API) and responsive motion styling.
- **Available Suites**: Studio, Executive One-Bedroom, and Two-Bedroom residences with self-check-in, instant hot water, 24/7 backup water storage, Smart TV with Netflix, and fast Wi-Fi.
- **Google Verified Ratings**: Integrated 4.5★ Google reviews with verified guest testimonials and links to Google Business Profile.
- **Location & Navigation**: Detailed street and satellite directions with Google Maps Plus Code (`WQ77+XH Kisumu`) and proximity highlights (Metropark Hotel, Victoria Comfort Inn, Pinecone Hotel).
- **SEO Travel Journal**: Search-engine-optimized long-form articles covering Kisumu stays, Lake Victoria excursions, and digital nomad workations with Schema.org JSON-LD structured data.
- **Direct Concierge**: Integrated WhatsApp instant booking and direct phone hotline (`0720 558431`).

## Tech Stack
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Audio**: Web Audio API Synthesizer

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
